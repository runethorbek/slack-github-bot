 # Ubiquitous Language

## Task

A work item stored in the Notion Tasks data source.

## Track

A larger area of work that can contain or relate to multiple tasks.

## Slack thread

One conversation boundary. The first user message defines the task/topic. Replies continue the same conversation.

## Slash command

Starts a new bot interaction from Slack.

## Reminder

A scheduled Slack message generated from task data.

## Stale track

A track that matches an explicit inactivity rule. The rule must be defined in code/configuration, not guessed by Gemini.
