slack-github-bot

A personal Slack assistant that uses Gemini to understand requests and works with Notion Tasks and People.

Private deployment

This deployment is for personal, private use. It is not a public service, and there is nothing here to sign up for or connect to.

Source code

The source code is available on GitHub: github.com/runethorbek/slack-github-bot. You are welcome to clone it and adapt it for your own use.

Built with

  • Slack
  • Notion
  • Gemini
  • Vercel
